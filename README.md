### 1. Постановка задачи

- Условие задачи
>Напишите программу на Java, которая выполняет следующие действия с
>двумерным массивом вещественных чисел (каждая строка может иметь
>разную длину):
>1. Считывает с консоли число строк N .Затем для каждой строки вво-
>дит количество элементов Mi, после чего вводит элементы строки,
>формируя массив размером N строк разной длины.
>2. Сортирует строки массива по возрастанию количества отрицатель-
>ных чисел в строке. Если количества равны, сортирует строки по
>возрастанию суммы положительных чисел.
>3. Находит и выводит максимальное число в массиве и его индексы
>(номер строки и позиция в строке).
>4. Выводит элементы массива в виде матрицы, заполняя недостающие
>элементы в строках символом ‘*’.
>5. Заменяет все числа в массиве на их обратные значения (1/число)
>и выводит полученный массив.

- 1. Считать с клавиатуры количество строк массива, для каждой строки
  запросить количество элементов и ввести сами числа, формируя таким
  образом двумерный массив разной длины.
- 2. Отсортировать строки массива по возрастанию количества отрицательных
  чисел. Если количество отрицательных чисел в строках одинаковое,
  отсортировать их по возрастанию суммы положительных чисел.
- 3. Найти наибольшее число во всем массиве и вывести его значение,
  а также номер строки и позицию элемента, в котором оно находится.
- 4. Вывести массив в виде матрицы. Если в какой-либо строке элементов
  меньше, чем в самой длинной строке, заполнить недостающие позиции символом *.
- 5. Заменить каждый элемент массива на его обратное значение (1/ число) и
  вывести полученный массив.

### 2. Входные и выходные данные

#### Данные на вход

Программа работает с двумерным массивом вещественных чисел, строки которого могут иметь разную длину.

На вход программа должна получать количество строк массива `N`. Для каждой строки вводится количество элементов `Mᵢ`, а затем сами элементы массива.

Количество строк и элементов будем считать натуральными числами. Вещественные числа могут быть как положительными, так и отрицательными. Поскольку в последнем пункте программы необходимо заменить каждое число на обратное значение (1 / число), нулевые элементы не допускаются.

Верхние границы количества строк, элементов и значений чисел в условии не указаны.

| Входные данные | Тип | min значение | max значение |
|---|---|---:|---:|
| N (Количество строк) | Натуральное число | 1 | Не указано |
| Mᵢ (Количество элементов в строке) | Натуральное число | 1 | Не указано |
| Aᵢⱼ (Элементы массива) | Вещественное число, не равное нулю | Любое отрицательное или положительное значение, кроме 0 | Не указано |

Таким образом, сначала вводится одно число `N`, затем для каждой строки вводится число `Mᵢ` и соответствующее количество вещественных чисел.

#### Данные на выход

Программа должна вывести результаты выполнения всех операций над массивом:

1. Отсортированный массив, в котором строки расположены по возрастанию количества отрицательных чисел. При равенстве количества отрицательных чисел учитывается сумма положительных чисел.
2. Максимальный элемент массива, а также номер строки и позицию элемента, в котором он находится.
3. Исходный массив в виде матрицы, где недостающие элементы строк обозначаются символом `*`.
4. Массив, в котором каждый элемент заменён на обратное значение (1 / число).

| Выходные данные | Тип | min значение | max значение |
|---|---|---|---|
| Элементы отсортированного массива | Вещественные числа | Зависят от входных данных | Зависят от входных данных |
| Максимальный элемент | Вещественное число | Зависят от входных данных | Зависят от входных данных |
| Номер строки максимального элемента | Натуральное число | 1 | N |
| Позиция максимального элемента в строке | Натуральное число | 1 | Mᵢ |
| Элементы матрицы | Вещественные числа или символ `*` | Зависят от входных данных | Зависят от входных данных |
| Элементы массива с обратными значениями | Вещественные числа | Зависят от входных данных | Зависят от входных данных |

Если в строках разное количество элементов, при выводе матрицы недостающие позиции заполняются символом `*`. Количество таких символов зависит от длины самой длинной строки и длины каждой отдельной строки.

### 3. Выбор структуры данных

Для хранения исходных данных будет использоваться двумерный массив `a` типа `double[][]`. Такой тип массива выбран, потому что по условию необходимо работать с вещественными числами, а количество элементов в каждой строке может быть разным.

Для хранения количества строк массива используется переменная `n` типа `int`. Количество элементов каждой строки вводится отдельно и используется при создании соответствующей строки массива.

Для выполнения сортировки, поиска максимального элемента и остальных операций используются дополнительные переменные.

| Назначение | Название переменной | Тип (в Java) |
|---|---|---|
| Количество строк массива | `n` | `int` |
| Исходный двумерный массив | `a` | `double[][]` |
| Количество элементов в строке при вводе | `m` | `int` |
| Счётчик строк при вводе и обработке | `i` | `int` |
| Счётчик элементов строки | `j` | `int` |
| Счётчик элементов при сортировке | `k` | `int` |
| Количество отрицательных чисел в первой сравниваемой строке | `neg1` | `int` |
| Сумма положительных чисел в первой сравниваемой строке | `sum1` | `double` |
| Количество отрицательных чисел во второй сравниваемой строке | `neg2` | `int` |
| Сумма положительных чисел во второй сравниваемой строке | `sum2` | `double` |
| Временный массив для обмена строк при сортировке | `t` | `double[]` |
| Максимальный элемент массива | `max` | `double` |
| Индекс строки максимального элемента | `il` | `int` |
| Индекс столбца максимального элемента | `jl` | `int` |
| Максимальная длина строки массива | `mc` | `int` |
| Массив для хранения обратных значений | `b` | `double[][]` |

При сортировке строк используется временный массив `t`, который позволяет менять строки местами без потери данных.

Для поиска максимального элемента используются переменные `max`, `il` и `jl`. Они позволяют сохранить максимальное значение и его расположение в массиве.

Переменная `mc` используется для определения длины самой длинной строки, чтобы при выводе массива в виде матрицы недостающие элементы можно было заменить символом `*`.

Для хранения обратных значений создаётся дополнительный двумерный массив `b`, имеющий такую же структуру, как исходный массив `a`.

### 4. Алгоритм

1. **Ввод исходных данных.**

   Сначала программа считывает количество строк массива `n`. Затем для каждой строки считывается количество элементов `m`, после чего вводятся сами вещественные числа. Таким образом формируется двумерный массив `a`, строки которого могут иметь разную длину.

2. **Сортировка строк массива.**

   После ввода всех данных программа сортирует строки массива по двум условиям.

   Сначала для каждой из двух соседних строк подсчитывается количество отрицательных чисел и сумма положительных чисел.

   Затем сравниваются полученные значения:
   - если в первой строке отрицательных чисел больше, чем во второй, строки меняются местами;
   - если количество отрицательных чисел одинаковое, сравниваются суммы положительных чисел. Строка с большей суммой перемещается ниже.

   Для сортировки используется метод пузырька. Если строки необходимо поменять местами, временно сохраняется первая строка, после чего строки меняются местами.

   В результате строки массива располагаются по возрастанию количества отрицательных чисел, а при равенстве этого количества — по возрастанию суммы положительных чисел.

3. **Поиск максимального элемента.**

   После сортировки программа находит максимальный элемент во всём массиве.

   Сначала за максимальное значение принимается первый элемент массива `a[0][0]`. Затем программа последовательно перебирает все строки и элементы массива. Если найденный элемент больше текущего максимума, его значение сохраняется в переменной `max`, а его индексы записываются в переменные `il` и `jl`.

   После завершения поиска программа выводит максимальный элемент, номер его строки и номер позиции в строке.

4. **Вывод массива в виде матрицы.**

   Для правильного отображения массива в виде матрицы программа сначала определяет длину самой длинной строки. Для этого все строки массива сравниваются по количеству элементов, а максимальная длина сохраняется в переменной `mc`.

   Затем программа выводит массив построчно. Если в строке есть элемент с текущим индексом, он выводится на экран. Если элементов в строке меньше, чем в самой длинной строке, вместо отсутствующих элементов выводится символ `*`.

5. **Вычисление обратных значений элементов.**

   В конце программы создаётся новый двумерный массив `b`, имеющий такую же структуру, как исходный массив `a`.

   Затем программа перебирает все элементы исходного массива и вычисляет для каждого обратное значение по формуле:

   `b[i][j] = 1.0 / a[i][j]`

   Если элемент равен нулю, в новый массив записывается `0`, чтобы избежать деления на ноль.

   После вычисления всех значений программа выводит полученный массив `b` на экран.

6. **Завершение программы.**

   После вывода массива с обратными значениями программа завершает свою работу.

### 5. Программа

```java
import java.io.PrintStream;
import java.util.Scanner;
public class Main {
    public static Scanner in = new Scanner(System.in);
    public static PrintStream out = System.out;
    public static void main(String[] args)  {
        int n = in.nextInt();
        double a [][] = new double[n][];
        
        // 1. ввод массива
        for (int i = 0;i < a.length; i++) {
            int m = in.nextInt();
            a[i] = new double[m];
            for (int j= 0;j < m; j++) {
                a[i][j]=in.nextDouble();
            }
        }
        
        // 2. Сортировка строк массива 
        for(int i =0;i < n-1; i++) {
            for(int j =0;j < n-1-i; j++) {
                
                //Считаем сумму положительных и количество отрицательных для a[j]
                int neg1 = 0;
                double sum1 = 0;
                for (int k = 0; k <a[j].length; k++) {
                    if (a[j][k] < 0) {
                        neg1++;
                    }
                    if (a[j][k] > 0) {
                        sum1 += a[j][k];
                    }
                }
                
                //То же самое для a[j+1]
                int neg2 = 0;
                double sum2 = 0;
                for (int k = 0; k < a[j + 1].length; k++) {
                    if (a[j + 1][k] < 0) {
                        neg2++;
                    }
                    if (a[j + 1][k]>0) {
                        sum2 += a[j + 1][k];
                    }
                }
                
                // Сравниваем и меняем местами при необходимости
                if (neg1>neg2 || (neg1==neg2 && sum1>sum2)) {
                    double t [] = a[j];
                    a[j]= a[j + 1];
                    a[j+ 1]= t;
                }
                
            }
        }
        
        //3.Нахождение и вывод максимального числа и его индексов
        double max = a[0][0];
        int il=0;
        int jl=0;
        for(int i =0;i< a.length; i++) {
            for(int j= 0;j< a[i].length; j++) {
                if (a[i][j] > max) {
                    max =a[i][j];
                    il =i;
                    jl =j;
                }
            }
        }
        out.println("макс элемент: "+max);
        out.println("строка: "+il + 1+","+" "+"столбец: "+jl + 1);
        
        //4.вывод массива в виде матрицы
        
        int mс = 0;
        for (int i= 0; i< a.length; i++) {
            if (a[i].length > mс) {
                mс= a[i].length;
            }
        }
        for (int i = 0; i< a.length; i++) {
            for (int j= 0; j< mс; j++) {
                if (j < a[i].length) {
                    out.print(a[i][j] + " "); 
                } else {
                    out.print("* "); 
                }
            }
            out.println(); 
        }
        
        //5.массив с обратными значениями
        double[][] b = new double[a.length][];
        
        for (int i= 0; i< a.length; i++) {
            b[i] = new double[a[i].length]; 
            for (int j= 0; j < a[i].length; j++) {
                if (a[i][j] != 0) {
                    b[i][j]= 1.0 / a[i][j]; 
                } else {
                    b[i][j] = 0; 
                }
            }
        }
        
        for (int i = 0; i< b.length; i++) {
            for (int j = 0; j< b[i].length; j++) {
                out.print(b[i][j] + " ");
            }
            out.println();
        }

        
    }
}
```

### 6. Анализ правильности решения

Каждый тест проверяет отдельную часть алгоритма.

#### 1. Тест на сортировку строк по количеству отрицательных элементов

- **Input:**
    ```text
    3
    4
    1 -2 3 -4
    3
    5 6 7
    3
    -1 2 3
    ```

- **Output (отсортированный массив):**
    ```text
    5 6 7
    -1 2 3
    1 -2 3 -4
    ```

- **Комментарий:** в первой строке нет отрицательных элементов, во второй — один, в третьей — два. Поэтому строки расположены в порядке возрастания количества отрицательных элементов.

#### 2. Тест на сортировку при одинаковом количестве отрицательных элементов

- **Input:**
    ```text
    3
    3
    -1 5 2
    3
    -2 1 1
    3
    -3 4 2
    ```

- **Output (отсортированный массив):**
    ```text
    -2 1 1
    -3 4 2
    -1 5 2
    ```

- **Комментарий:** во всех строках по одному отрицательному элементу. Поэтому сортировка выполняется по сумме положительных элементов: 2, 6 и 7.

#### 3. Тест на поиск максимального элемента и его индексов

- **Input:**
    ```text
    2
    3
    -5 2 10
    2
    4 7
    ```

- **Output:**
    ```text
    макс элемент: 10
    строка: 1, столбец: 3
    ```

- **Комментарий:** максимальным элементом является число 10. После сортировки оно находится в первой строке и третьем столбце.

#### 4. Тест на обработку строк разной длины

- **Input:**
    ```text
    3
    2
    1 2
    4
    3 4 5 6
    1
    7
    ```

- **Output (отсортированный массив):**
    ```text
    1 2 * *
    7 * * *
    3 4 5 6
    ```

- **Комментарий:** строки имеют разную длину. При выводе массива недостающие элементы заменяются символами `*`. Тест проверяет правильность определения максимальной длины строки.

#### 5. Тест на вычисление обратных значений

- **Input:**
    ```text
    2
    3
    2 -4 0.5
    2
    -2 4
    ```

- **Output (массив обратных значений):**
    ```text
    0.5 -0.25 2.0
    -0.5 0.25
    ```

- **Комментарий:** каждый элемент заменяется обратным ему значением.

### Вывод

Выбранные тесты проверяют оба критерия сортировки, поиск максимального элемента, обработку массива с разной длиной строк и вычисление обратных значений. 

**Примечание:** в программе для нулевого элемента обратное значение заменяется на 0, поскольку деление на ноль невозможно. В приведённых тестах ноль не используется.
